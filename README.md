# 예약 감시 매크로 (CGV / 화담숲)

CGV 영화 예매와 화담숲 예약 등, 자리가 금방 차는 사이트에서 **빈자리가 날 때까지 자동으로 새로고침하며 감시**하다가, 자리가 나면 알림음과 함께 예약 버튼을 눌러주는 간단한 도구입니다.

> 로그인·캡차·결제는 여러분이 직접 합니다. 매크로는 "자리 감시 + 첫 클릭"까지만 도와줍니다.

## 주의사항

- **개인적으로 정당하게 이용 가능한 예약에만** 사용하세요.
- 사이트 이용약관이 자동화를 금지할 수 있습니다. 사용 전 확인하세요.
- `refresh_sec` 를 너무 짧게(1초 미만) 두면 사이트에 부담을 주고 IP/계정이 차단될 수 있습니다. **3초 이상**을 권장합니다.
- 재판매/암표 등 부정한 목적으로 쓰지 마세요.

## 설치

```bash
pip install -r requirements.txt
playwright install chromium
```

## 설정

`config.example.json` 을 `config.json` 으로 복사한 뒤 값을 채웁니다. (`config.json` 은 개인 정보가 담기므로 git 에 올라가지 않습니다.)

```bash
cp config.example.json config.json
```

각 항목 의미:

| 키 | 설명 |
| --- | --- |
| `url` | 감시할 예약 페이지 주소. **실제로 예매/예약 버튼이 보이는 페이지**를 넣으세요. |
| `needs_login` | true 면 시작 후 직접 로그인할 시간을 줍니다. |
| `refresh_sec` | 새로고침 간격(초). 3 이상 권장. |
| `available_selector` | "자리 있음"을 나타내는 버튼/문구. Playwright 셀렉터 문법. |
| `sold_out_text` | 이 문구가 보이면 아직 자리 없음으로 판단(예: `매진`, `마감`). |

## 사용법

```bash
python watcher.py cgv        # CGV 감시
python watcher.py hwadamsup  # 화담숲 감시
```

실행하면:
1. 브라우저가 열리고 예약 페이지가 뜹니다.
2. 직접 로그인(필요하면 원하는 영화/날짜/시간까지 선택)한 뒤, 터미널에서 Enter.
3. 자리가 날 때까지 자동 새로고침하며 감시합니다.
4. 자리가 나면 **삑 소리**가 나고 예약 버튼을 눌러줍니다. 이후 좌석 선택·결제는 직접 마무리하세요.

## 셀렉터(selector) 맞추는 법

사이트 화면 구조는 자주 바뀌므로 `config.json` 의 셀렉터를 실제 페이지에 맞게 조정해야 정확히 동작합니다.

1. 감시할 페이지를 브라우저에서 엽니다.
2. F12(개발자 도구) → 예약/예매 버튼을 우클릭 → "검사".
3. 버튼에 보이는 글자를 `text=글자` 형태로 넣거나, `#아이디`, `.클래스` 셀렉터를 넣습니다.
   - 예: 버튼 글자가 "예매하기" → `"available_selector": "text=예매하기"`
4. 자리가 없을 때 뜨는 "매진/마감" 문구를 `sold_out_text` 에 넣습니다.

> 참고: CGV 예매는 영화 → 극장 → 날짜 → 시간 → 좌석 순의 여러 단계라, `url` 에 **원하는 상영시간표 페이지**를 넣고 감시하는 게 가장 정확합니다. 화담숲은 원하는 날짜의 예약 페이지 URL 을 넣으세요.

## 파일 구성

- `watcher.py` — 감시 엔진(설정을 읽어 실행)
- `common.py` — 브라우저 실행·알림음·감시 루프 헬퍼
- `config.example.json` — CGV / 화담숲 설정 예시
- `requirements.txt` — 의존성(Playwright)
